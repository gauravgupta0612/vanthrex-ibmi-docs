# Keyboard shortcuts

| Keys | Action | Where |
|---|---|---|
| **Ctrl+Alt+I** | IBM i quick menu | Anywhere |
| **Ctrl+Alt+C** | Compile the current member or IFS file | Editor |
| **Ctrl+Enter** | Run the SQL statement under the cursor | `.sql` editor |
| **Ctrl+Shift+Enter** | Run the whole SQL script (or the selection), statement by statement | `.sql` editor |
| **Ctrl+Alt+L** | Run a CL command with your library list | Anywhere (connected) |
| **Ctrl+Alt+J** | Go to anything: members, objects, recent items | Anywhere (connected) |
| **Ctrl+Alt+Shift+F** | Instant search in indexed sources | Anywhere (connected) |
| **Ctrl+Alt+R** | Run the selection as CL or SQL | Editor (connected) |
| **Ctrl+Alt+.** | Close the open block (ENDIF, ENDDO…) | RPG editor |
| **Ctrl+Alt+W** | Surround the selection with IF, MONITOR, DOW… | RPG editor (selection) |
| **Ctrl+/** | Toggle RPG comment | RPG editor |
| **Ctrl+Alt+PageDown / PageUp** | Next / previous procedure | RPG editor |
| **Ctrl+Alt+A** | IBM i tools for this source (Developer Toolbox) | Editor |
| **Ctrl+Alt+Shift+T** | Toggle value (*ON / *OFF, AND / OR, = / <>…) | RPG editor |
| **Ctrl+Alt+B** | Toggle a bookmark on the line | Editor |
| **Ctrl+Alt+Shift+B** | List bookmarks | Anywhere |
| **Ctrl+Alt+K** | 5250-style command line | Anywhere (connected) |
| **Ctrl+Alt+P** | PASE terminal | Anywhere (connected) |
| **Ctrl+Alt+E** | AI: change the selected code (shown as a diff first) | Editor |
| **Ctrl+Alt+O** | Search objects | Anywhere (connected) |
| **Ctrl+Alt+F** | Search source code | Anywhere (connected) |
| **Ctrl+Alt+G** | Debug the program of the current source | RPG / CL editor |
| **Ctrl+Alt+D** | Cycle source dates: date → sequence + date → hidden | Member editor |
| **F4** | Prompt the fixed-format spec (RPG, DDS) or CL command at the cursor | RPG / DDS / CL editor |
| **F12** | Go to definition (also into /COPY members) | RPG editor |
| **Shift+F12** | Find all references | RPG editor |
| **F2** | Rename symbol (scoped to the procedure) | RPG editor |
| **Ctrl+click** | Open a /COPY or /INCLUDE member | RPG editor |
| **Ctrl+S** | Save the member to the IBM i | Member editor |

On a Mac, use **Cmd** instead of **Ctrl**.

To change a key: **File → Preferences → Keyboard Shortcuts**, search for *Vanthrex*. The full list of commands is on the [Commands](commands.md) page.
