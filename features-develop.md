# Develop

Write, check, compile and debug RPG, CL, COBOL and DDS — alone or as a team.
{: .fs-6 .fw-300 }

![Checks while you type, with the fix one click away.]({{ "/images/quick-fix.png" | relative_url }})
*Checks while you type, with the fix one click away.*

| Page | What you get |
|---|---|
| [Edit & compile](features-edit-compile.md) | Compile with one key, errors on the right line, fixed → free conversion, every version kept. |
| [SEU-style editing](features-seu-editing.md) | Source dates, F4 prompters and member lists with dates — what SEU users expect. |
| [RPG code checks](features-rpg-checks.md) | Warnings as you type, with quick fixes and per-rule switches. |
| [Search & navigation](features-search-navigation.md) | Find objects and source, where used, go to definition into /COPY members, rename. |
| [Procedure & copybook tools](features-procedure-tools.md) | Generate prototypes, extract code into procedures, find unused /COPY members. |
| [Call graph & impact analysis](features-call-graph.md) | Interactive diagram of callers and callees, with Copy as Mermaid. |
| [Locks & conflicts](features-locks-conflicts.md) | See who has a member, ask them to release it, never overwrite someone else's change. |
| [Git for IBM i source](features-git.md) | Export libraries to Git, move changes both ways, the history of any member. |
| [AI assistant](features-ai.md) | `@vanthrex` in the chat: explain, document, review, modernize, tests, fix compile errors, SQL on your tables. |
| [Debugging](debugging.md) | Breakpoints, stepping, variables and call stack for RPG, COBOL and CL. |
| [Source Change Calendar](features-3-2.md#source-change-calendar) *(3.2)* | A year of member changes as a heat map; click a day to list the members. |
| [VS Code tasks for IBM i](features-3-3.md#vs-code-tasks-for-ibm-i) *(3.3)* | Run CL or PASE commands on the IBM i from `tasks.json`. |
| [50 more developer tools](features-3-3.md#50-more-developer-tools) *(3.3)* | Sort, quote and join lines, SQL from a CREATE TABLE, READ and cursor loops, CL templates… in `Ctrl+Alt+A`. |
| [50 more developer tools, second batch](features-3-3.md#50-more-developer-tools-second-batch) *(3.3)* | RPG IFS read / write, data areas and queues, JSON from variables; SQL → JSON, UPDATE / DELETE previews, audit columns and triggers; CL retries, SBMJOB, save files; IBM i date, hex and type converters. |
