# Features

Every feature, what it does, why it helps and how to use it.
{: .fs-6 .fw-300 }

| Area | What you get |
|---|---|
| [Connect & browse](features-connect-browse.md) | Set up connections — several systems at once — then browse libraries, source files, members, objects and the IFS. |
| [Edit & compile](features-edit-compile.md) | Compile with one key, see errors on the right line, convert fixed format (H, F, D, P and C specs) and never lose a version. |
| [SQL & table data](features-sql-data.md) | Run Db2 for i SQL with autocomplete and edit table data in a safe grid. |
| [SEU-style editing](features-seu-editing.md) | Source dates, F4 prompters and member lists with dates — what SEU users expect, in VS Code. |
| [Locks & conflicts](features-locks-conflicts.md) | See who has a member, ask them to release it, and never overwrite someone else's change. |
| [Search & navigation](features-search-navigation.md) | Find objects and source, see where things are used, and navigate RPG like a modern language. |
| [RPG code checks](features-rpg-checks.md) | Warnings as you type, with quick fixes and per-rule switches. |
| [System, jobs & messages](features-system.md) | Dashboard, active jobs, message replies, the CL runner and spooled files. |
| [Object tools](features-object-tools.md) | Object information, who has an object locked, compare two libraries, and modules & exports. |
| [SQL power tools](features-sql-tools.md) | Generate SQL (DDL), run whole scripts, **Explain** query performance, SQL history and saved queries. |
| [Procedure & copybook tools](features-procedure-tools.md) | Generate prototypes, extract code into procedures, and find unused /COPY members. |
| [AI assistant](features-ai.md) *(new in 0.6)* | `@vanthrex` in the chat: explain, document, review, modernize, unit tests, fix compile errors, SQL against your real tables. |
| [Git for IBM i source](features-git.md) *(new in 0.6)* | Export libraries to Git, get and upload changes, commit & push, and the history of any member. |
| [Call graph & impact analysis](features-call-graph.md) *(new in 0.6)* | Interactive diagram of callers and callees, with Copy as Mermaid. |
| [Insights](features-insights.md) *(new in 0.8)* | Index advisor, DEV ↔ PROD table data compare, message help on hover and a job log analyzer. |
| [System tools](features-system-tools.md) *(new in 0.9)* | Journal explorer (who changed which rows), authority checker with the fix, data queue & data area viewer/editor, and a PTF & system health report. |
| [Work with… (WRK screens)](features-work-with.md) *(new in 0.11)* | Subsystems, job queues, output queues, job scheduler, user profiles, system values, audit journal, save files and TCP/IP. |
| [Operations](features-operations.md) *(new in 1.0)* | Storage & cleanup advisor, live alerts, message files, field finder and object promotion DEV → TEST → PROD. |
| [Data, performance & quality](features-data-quality.md) *(new in 1.1)* | Import / export Excel, CSV, JSON; performance monitor; code metrics; documentation from source; RPGUnit tests. |
| [Safe on production](features-safety.md) *(new in 1.2)* | Production / read-only protection, self-check of the system, errors that explain what to do. |
| [See and share](features-see-share.md) *(new in 1.3)* | 5250 screen preview, database diagrams, compare two systems, spooled files to PDF / e-mail. |
| [New in 2.0](features-2-0.md) *(new in 2.0)* | 20 helpers: RPG code from a table, SQL formatter, find & replace across members, compile changed members, print preview, test data, submit & watch, library list sets and more. |
| [Security Admin and more](features-security-admin.md) *(2.1)* | User profiles, groups and authorization lists for *SECADM users; objects out of sync with source, release notes, templates, row locks, running SQL, exit points, bulk authority, job details, QHST, indicator usage, IFS CCSID, ping and web API calls. |
| [Debugging](debugging.md) | Breakpoints, stepping, variables and call stack for RPG, COBOL and CL (new in 0.5). |

New to the extension? Start with [Installation](installation.md) and [Your first connection](first-connection.md).
